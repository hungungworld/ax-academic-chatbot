# 조사메모: LangGraph (DeepWiki 조사)

DeepWiki의 답변을 정리했습니다. 문서 이름은 DeepWiki가 알려 준 대로만 적었고, 확인되지 않은 것은 확인되지 않았다고 표시했습니다.

## ① 노드, 엣지, 상태 (비전공자용)

| 용어 | 쉬운 설명 |
|---|---|
| **노드(Node)** | 일을 하는 단계 하나입니다. 업무 흐름의 "담당 창구"와 같습니다. 예를 들어 AI에게 질문하는 단계나 도구를 쓰는 단계입니다. 실제로는 함수 하나입니다. |
| **엣지(Edge)** | 단계 사이의 연결선으로, 다음에 어느 단계로 갈지 정합니다. 조건에 따라 길이 갈라지는 "조건부 엣지"도 있습니다. |
| **상태(State)** | 모든 단계가 함께 읽고 고쳐 쓰는 공용 메모장 또는 신청서입니다. 흐름이 진행되면서 내용이 갱신됩니다. |

**참고한 문서**
- 3.1 StateGraph API: 노드, 엣지, 상태 스키마 셋 모두
- 3.4 State Management and Channels: 상태 값이 노드 사이에서 전달되고 합쳐지는 방식
- 3.5 Control Flow Primitives: 조건부 엣지와 경로 선택
- 3 Core Execution System: 전체 개요

## ② 가장 간단한 그래프 예시

- **문서 이름: 확정하지 못했습니다.** DeepWiki는 `Graph API overview`와 `Quickstart`가 문서 목록에 있다고만 했고, 어느 쪽에 이 예시가 있는지는 확인하지 못했습니다.
- 확인된 가장 간단한 예시는 노드 하나짜리 `StateGraph`입니다. 출처는 `libs/langgraph/langgraph/graph/state.py`의 `StateGraph.add_node` 설명입니다. 독립된 문서 페이지는 아닙니다.
- 이 예시는 `x`에 1을 더하는 노드 하나를 `START`에 연결해 `{'x': 1}`을 넣으면 `{'x': 2}`가 나옵니다.
- 처음 배우신다면 위의 3.1 StateGraph API부터 보시는 편이 안전합니다.
